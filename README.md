# Лента мира (World Feed) — Reddit, Twitter и Instagram для твоего ролевого мира

Расширение для SillyTavern: окно-«браузер» с тремя вкладками: тёмный Reddit, Twitter (X) и Instagram, где жители игрового мира обсуждают события твоей ролевой. Лучше всего работает там, где соцсетей быть не может: средневековье, эльфы, античность, космос.

- Посты и комментарии персонажей мира: интернет-сленг, эмодзи, мемные форматы (AITA, TIL, «это база»), срачи в комментах.
- Сабреддиты и ники придумываются под мир (r/Beleriand, u/not_a_balrog_tbh…).
- Посты пишутся по свежим событиям чата. Комментаторы узнают о них из слухов, поэтому могут ошибаться и спорить.
- **Три соцсети с разным характером — как вкладки браузера.** Reddit — посты, сабреддиты, срачи в комментах. Twitter — короткие резкие твиты до 280 знаков, горячие тейки, BREAKING от инсайдеров, стан-аккаунты, ратио, галочки у знати, хэштеги и «Актуальные темы». Instagram — у каждого поста своё фото «снято на телефон» по кадру, который модель придумывает для этого поста; герои игры попадают в кадр, только если пост про них. Сторис-фильтр по аккаунтам, геометки, комменты. У каждой вкладки свой промт и своя лента.
- **Свои посты.** На Reddit — кнопка «✏ Пост» (сообщество, заголовок, текст), в Twitter — поле «Что происходит?» над лентой, в Instagram — «⊕ Публикация» (своё фото или его описание). Жители сразу отвечают (можно выключить).
- Можно комментировать самой: кнопка «Загрузить ещё комментарии» приводит в тред новых людей, и они отвечают тебе.
- Лайки, награды, сворачивание веток, фильтр по сабреддитам, сортировка «Новое / Горячее / Топ», «Читать полностью» для длинных постов.
- Персонаж игрока в ленту не пишет: комменты от его имени появляются, только когда их пишешь ты сама. Другие имена персонажа можно указать в настройках.
- Работает на телефоне: окно на весь экран, кнопка «Назад» закрывает настройки и ленту.
- **В промпт ролевой игры не попадает.** Это чистое развлечение.

## Установка

«Расширения» → «Установить расширение» → вставить:

```
https://github.com/ffyousupoff-glitch/world-feed
```

Перезагрузить страницу (F5).

## Как открыть

- плавающая кнопка 📰 сбоку (перетаскивается);
- меню-палочка → «Лента мира»;
- команда `/feed`.

Внутри нажми «⟳ Обновить ленту».

## Настройки (⚙ в окне ленты)

- **Подключение**: основное подключение чата, профиль из Connection Manager (например, дешёвая модель только для ленты) или свой API: адрес, ключ, модель. Свой API ходит через сервер таверны, поэтому CORS не мешает. Кнопка «Проверить подключение» есть для каждого режима.
- **Промт Реддита** и **Промт Твиттера** (отдельно): системный промпт целиком, с плейсхолдерами `{{user}}`, `{{char}}`, `{{language}}`. Формат JSON и лимиты длины расширение добавляет само.
- **Посты**: сколько постов за раз, комментариев на пост, лимиты длины поста и коммента.
- **Контекст**: сколько последних сообщений чата читать, потолок в символах, учитывать ли карточку и персону. Видна оценка расхода токенов.
- **Фото к постам** Reddit/Twitter (по умолчанию выключены) и **фото Instagram** (сами рисуются N новых постов за обновление, по одному, пока листаешь; стиль настраивается): генерация идёт через расширение Hermes Images, если оно установлено.

## Данные

Своя лента у каждого чата, хранится в метаданных чата (`chatMetadata.worldFeed`); у каждого поста поле `net` — `reddit`, `twitter` или `insta`. Очистка стирает только открытую вкладку. Настройки лежат в `extension_settings["world-feed"]`.

Для отладки в консоли: `window.WorldFeed`.
